

##  Funções do Spark x Funções do Python (conceito essencial)

### 🔍 O que acontece de verdade

### ✅ Função do Spark (nativa)

```python
from pyspark.sql import functions as F

F.dayofweek("created_at")
```

* ✅ Executa na **JVM (Scala)**
* ✅ Otimizada pelo **Catalyst Optimizer**
* ✅ Paralelizada nos **executors**
* ✅ Aparece como **Project** no `explain`
* ❌ **Não executa Python linha a linha**

👉 Isso **cria uma expressão lógica**, não uma execução imediata.

---

### ❌ Função Python comum (User-Defined Function)

```python
def minha_funcao(x):
    return x + 1
```

* ❌ Executa no **Python local**
* ❌ Não entende DataFrame distribuído
* ❌ Não paraleliza
* ❌ Não aparece no plano Spark

---

### 🚫 Erro clássico de iniciante

```python
df.withColumn("x", minha_funcao(df["coluna"]))
```

* ❌ Não funciona corretamente
* ❌ Ou força uso de **Python UDF** (pior cenário)

---

## 🧠 Como o Spark “lê” o código

Quando você escreve:

```python
F.dayofweek("created_at")
```

O Spark entende como:

> “Crie uma **instrução lógica** para calcular o dia da semana no plano de execução”

E **não** como:

> “Execute agora em Python”

---

## 📊 Comparação direta
O que é JVM?
JVM = Java Virtual Machine
É o ambiente de execução onde rodam aplicações Java/Scala.
O Apache Spark é escrito principalmente em Scala, que roda dentro da JVM.

O que é UDF (User Defined Function)?
UDF = Função definida pelo usuário
É quando você escreve uma função em Python e pede para o Spark usá-la no DataFrame.


👉 Quando você usa funções nativas do Spark (F.*), elas executam dentro da JVM, não no Python.

| Tipo                 | Onde executa | Otimização | Performance |
| -------------------- | ------------ | ---------- | ----------- |
| Função Spark (`F.*`) | JVM          | Catalyst   | ⭐⭐⭐⭐⭐       |
| Python UDF           | Python       | ❌          | ⭐           |
| Função Python comum  | Python local | ❌          | ❌           |
