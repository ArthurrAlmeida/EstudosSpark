# DataFrame no Apache Spark

## O que é um DataFrame?

Um **DataFrame** no Spark é uma estrutura de dados distribuída, organizada em **linhas e colunas**, semelhante a uma tabela de banco de dados ou a um DataFrame do Pandas, porém projetada para processamento em larga escala.

### Principais características

- Estrutura tabular (linhas e colunas)
- Imutável (toda transformação gera um novo DataFrame)
- Possui schema conhecido
- Lineage preservada
- Colunas podem ter tipos de dados diferentes
- Suporta análises comuns:
  - Filtrar
  - Agrupar
  - Ordenar
- O Spark pode otimizar essas análises por meio de planos de execução

---

## Lazy Evaluation

No Spark, as transformações em DataFrames **não são executadas imediatamente**.

### Funcionamento

- O Spark registra as transformações
- O processamento real ocorre somente quando uma **ação** é executada
- Esse comportamento é chamado de **Lazy Evaluation**

### Por que isso é importante?

- Permite otimizações automáticas
- Evita processamento desnecessário
- Melhora a performance das aplicações

Exemplos de ações:
- `show()`
- `count()`
- `collect()`
- `write()`

---

## Tipos de Dados no Spark

O Spark utiliza um sistema de tipos forte e bem definido para DataFrames.

### Tipos primitivos

- ByteType
- ShortType
- IntegerType
- LongType
- FloatType
- DoubleType
- DecimalType
- StringType
- BinaryType
- BooleanType
- TimestampType
- DateType

### Tipos complexos

- ArrayType
- MapType
- StructType
- StructField

Esses tipos permitem trabalhar com dados estruturados e semi-estruturados, como arquivos JSON.

---

## Schema

O **schema** define a estrutura do DataFrame, incluindo colunas, tipos de dados e nulabilidade.

### Como definir o schema

- Permitir que o Spark infira automaticamente a partir dos dados
- Definir o schema manualmente

### Vantagens de definir o schema manualmente

- Tipos corretos desde a leitura
- Melhor performance
- Evita overhead de inferência
- Reduz erros em ambientes produtivos

---

## Resumo

- DataFrames são a base do processamento estruturado no Spark
- São imutáveis e possuem schema definido
- Utilizam Lazy Evaluation para otimização
- O schema é fundamental para performance e confiabilidade
